# 사용·설치·실행 안내

## 웹서비스 사용

[여기 DC 돼요?](https://grand-site-dc.vercel.app)에서 ‘부지 검토 시작’을 누르고 주소 또는 좌표를 검색합니다. 지도를 선택해도 됩니다. 확인된 제약과 중요한 미확인을 먼저 읽고, 필요한 경우 상세 사업조건을 넣어 최대 4개 후보를 담습니다. 비교 후 ‘부지 검토 보고서’를 열어 PDF로 저장합니다. 내부 사업정보나 AI 생성 없이 기본 검토·보고서가 가능합니다.

[검증 예제](예제입력.md)를 그대로 입력하면 최소 대지 15,000㎡·부족 5,000㎡·금융비용 60억원을 확인할 수 있습니다. 공개 좌표에 합성 조건을 넣은 예시입니다. 실제 온라인 근거는 시점에 따라 달라집니다. 실패·부분 응답은 ‘제약 없음’이 아닙니다.

보고서는 여는 시점의 입력·근거를 고정합니다. 입력이나 조회 결과가 바뀌면 보고서를 다시 열어 최신 내용을 반영하세요. AI 의견은 선택 사항이며 변경 시 무효화됩니다. 현재 운영 AI는 오류로 종료되었으나 기본 보고서는 유지됩니다.

후보·입력은 이 탭의 sessionStorage에 허용한 항목만 보관합니다(24시간·96KiB). 소개 페이지 왕복과 새로고침 복원을 지원하지만 탭 종료·브라우저 정책·보관기한·저장 실패 뒤 복구를 보장하지 않습니다. 온라인 자료·AI 의견은 다시 확인합니다. ‘검토 내용 지우기’는 현재 입력과 후보를 지웁니다.

## 개발자 새 폴더 실행

private 저장소 접근 권한과 Git, Node.js 24, npm, Python 3.12가 필요합니다. macOS arm64에서 새 폴더 재현을 확인했습니다. 현재 공개자료 번들은 저장소에 있으므로 대규모 재수집은 필요하지 않습니다.

```sh
git clone --branch prototype https://github.com/seungminyi-byte/Camp_It_Ralph.git Camp_It_Ralph
cd Camp_It_Ralph
node --version
python3 --version
npm --prefix prototype ci
npm --prefix prototype run typecheck
npm --prefix prototype run lint
npm --prefix prototype test
python3 data-pack/scripts/validate_out.py
npm --prefix prototype run build
npm --prefix prototype run dev -- --host 127.0.0.1 --port 5209 --strictPort
```

`http://127.0.0.1:5209/`와 `/project`, `/team`, `/review`를 열 수 있습니다. 서버 종료는 해당 터미널의 `Ctrl+C`입니다. 특정 제품 배포를 재현하려면 설치 전에 `git checkout bb1828450564813d9d91d23142409fa480529106`을 실행합니다. 최신 문서는 prototype에 후속 반영될 수 있습니다.

개발 서버의 `/api/*`는 실제 운영 API로 전달됩니다. 주소·좌표와 선택한 AI 요청이 전송되며, 로컬 `prototype/api` 수정은 Vite에서 실행되지 않습니다. `.env`·`.vercel`·기존 node_modules·브라우저 인증을 복사하지 않고 비밀값을 명령·코드·브라우저에 넣지 않습니다. 지도와 온라인 조회에는 인터넷이 필요합니다.

## 합성 통합검사와 PDF 검사

```sh
npm --prefix prototype run test:e2e:install
npm --prefix prototype run build
npm --prefix prototype run test:e2e
```

E2E는 Chromium을 설치한 뒤 고정 응답·합성 입력으로 5208 서버를 자동 시작·종료합니다. 운영 API의 성공 검사가 아닙니다. 별도 성능·PDF 검사는 한 터미널에서 `npm --prefix prototype run test:e2e:serve`를 켜고, 다른 터미널의 저장소 루트에서 아래를 실행합니다.

```sh
npm --prefix prototype run test:performance
npm --prefix prototype run test:pdf
python3 prototype/e2e/inspect-pdf.py prototype/e2e/artifacts/pdf --render
node prototype/e2e/security-scan.mjs
```

PDF 검사에는 pypdf·pdfplumber 및 Poppler의 pdftoppm이 필요합니다. 설치가 필요하면 별도 Python 가상환경을 사용합니다. 모든 PNG를 열어 잘림·겹침·한글·표·페이지 누락을 확인하고 5208 서버를 `Ctrl+C`로 종료합니다. 다른 작업의 포트나 서버를 종료하지 않습니다. 상세 명령·조건은 저장소 docs/RUNNING.md와 prototype/e2e/README.md에 있습니다.

기존 배포 workflow는 prototype/** 또는 workflow 변경의 prototype push와 수동 실행에 반응합니다. 문서만 추가한 PR을 새 제품 배포라고 해석하지 않습니다. [검증 요약](검증요약.md)과 [운영 출력 기록](operating-report-example/예제입력과_출력기록.json)을 함께 확인하세요.
