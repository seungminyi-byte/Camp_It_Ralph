# 부지 검토 보고서 — 검수 예시

현재 제품의 실제 인쇄 화면을 Chromium A4 PDF로 출력하고, 전체 53쪽을 실행자와 총괄이 각각 시각·수치 검수한 예시입니다. 공개자료 번들과 **합성 온라인 응답·가상 입력**을 사용했습니다. 특정 부지의 실제 인허가·전력 공급·사업 적합성을 판정하는 자료가 아닙니다.

| 파일 | 쪽수 | 확인한 예시 |
|---|---:|---|
| [empty.pdf](empty.pdf) |6|상세조건·차입 미입력, AI 없이 기본 보고서|
| [numeric.pdf](numeric.pdf) |9|연면적30,000㎡/200%/50%/4층→최소대지15,000㎡·부족5,000㎡; 차입1,000억원/6%/12개월→60억원; 총액2,000/2,300억원 차이300억원|
| [zero.pdf](zero.pdf) |7|명시적0원과 미입력의 구분|
| [long-partial.pdf](long-partial.pdf) |25|현재 후보E와 저장 후보A~D 구분, 일부 조회 미완료, 긴 후보명·협의 메모 보존|
| [ai.pdf](ai.pdf) |6|검수용 합성 AI 의견을 명시 선택한 부록; 기본은AI 미포함|

첫 장의 위치·제약·중요 미확인·비교 요약·다음 확인과 상세 근거·기준일·조회시각을 확인했습니다. 금융표12개 각9셀과 긴 메모의 끝 표식을 추출해 대조했습니다. PDF 속 보고서 기준시각과 snapshot ID는 출력 당시 조건을 가리킵니다. 이후 사용자 입력이나 온라인 자료가 바뀌어도 이 파일은 자동 갱신되지 않습니다.

전체 파일의 SHA-256·바이트·페이지 수·snapshot ID는 [manifest.json](manifest.json)에 있습니다. 이 예시는 검수용 파일이며 실제 현업 보고에는 최신 자료와 담당 기관·설계·금융 조건을 다시 확인해야 합니다. 운영 API 연결·실기기 OS 인쇄/Safari 검증은 이 예시의 확인 범위에 포함되지 않습니다.
