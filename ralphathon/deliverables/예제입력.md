# 검증용 예제 입력

사업조건은 모두 **합성 값**이며 실제 투자·공급·인허가 사실이 아닙니다. 좌표는 공개 위치 예시입니다. 세종 반곡동 부근 `36.4967, 127.3007`에서 조회하되 실시간 온라인 근거·점수는 출력시점에 달라집니다. 이 예시는 AI 없이 가능합니다.

1. `/review`에서 검색창에 `36.4967, 127.3007`을 입력해 검토합니다. 또는 실제 주소 검색으로 후보를 찾고 결과 좌표를 확인합니다.
2. 상세조건을 열어 신축·계획 연면적 직접 입력을 유지합니다. 연면적 **30,000㎡**, 용적률 **200%**, 건폐율 **50%**, 지상층수 **4층**, 대지 **10,000㎡**를 입력합니다.
3. 평균 차입잔액 **1,000억원**, 비교할 연 금리 **6%**, 기간 **12개월**을 확인합니다. 다른 비용은 알 수 없으면 비워 둡니다.
4. 후보를 담고 다른 공개 좌표도 같은 기준으로 검토·담아 비교할 수 있습니다. 새 지점의 부지별 면적·비용·협의 입력은 비어 있으므로 숫자로 비교할 때는 해당 지점에도 값을 직접 입력합니다. 최대 4곳이며 5번째는 기존 후보를 삭제한 뒤 추가합니다.
5. 보고서 항목을 펼쳐 **부지 검토 보고서**를 엽니다. AI는 생성하지 않아도 됩니다. 첫 장의 위치·주요 제약·미확인·비교 요약·다음 확인과 상세 근거를 읽고 ‘PDF 저장’을 누릅니다.

독립 기대값은 다음과 같습니다.

| 항목 | 계산 | 기대 결과 |
|---|---|---|
| 최소 대지 | max(30,000/2, 30,000/4/0.5) | 15,000㎡ |
| 대지 부족 | 15,000−10,000 | 5,000㎡ |
| 평 변환 | 저장소 기존 근사 계수 사용 | 10,000㎡ ↔ 3,025평 |
| 지연 금융비용 | 1,000억원×0.06×12/12 | 60억원 |
| 차입잔액 미입력 / 명시 0 | 결측과 0을 구분 | 계산 보류 / 0원 |
| 같은 완전한 총액 방식의 후보 2,000/2,300억원 | 큰 금액−작은 금액 | 300억원 차이 |
| 항목 누락 또는 비용 방식 혼합 | 비교 근거 불완전 | 최저비용·차액 판단 보류 |

위 면적은 모든 연면적이 지상·용적률 산입이고 층별 면적이 같다는 단순 가정입니다. 옥외설비·주차·높이·이격거리와 실제 공급·허가는 별도 확인합니다. 온라인 조회 실패는 PDF에도 그대로 남겨야 합니다. 특정 점수·용도지역·규제 없음은 예제의 고정 기대값이 아닙니다.
