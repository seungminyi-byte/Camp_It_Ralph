# 이관 근거

이 폴더는 03M/04A 구현 검수와 03L 공식자료 조사에서 기존 문서가 링크한 41개 파일의 선별 사본입니다. 원본 세션 JSONL 전체를 넣지 않습니다. 원본 파일명·원본/사본 SHA-256·바이트·로컬 경로 치환 여부는 [manifest](transfer-manifest.json)에 있습니다. 비밀값 고신뢰 패턴을 검사한 뒤 개인 로컬 경로를 `[WORKSPACE]`, `[USER_HOME]`으로 바꿨으므로 일부 파일은 원본과 해시가 다릅니다. 시험용 가짜 키 문자열은 실제 비밀이 아닙니다. 패턴검사는 알려지지 않은 모든 비밀 형태 부재의 증명이 아닙니다.

`checks/`의 실패·red 로그는 실제 실패 재현의 이력이며 성공으로 바꿔 쓰지 않습니다. `legal-audit/`는 당시 공식자료 조회 결과이며 현재 적용법 전체에 대한 새 법률조사가 아닙니다. 원본 manifest 속 작업 경로는 이력이고 재현 명령의 전제가 아닙니다. 현행 실행은 [RUNNING](../../docs/RUNNING.md), 현재 재현·운영 검증은 [09](../implementation/09-reproduction-deployment.md)를 따릅니다.
