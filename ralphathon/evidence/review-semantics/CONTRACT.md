# 요약 의미 변경의 검증 계약

기준: 단계 1 `389f0cd`, 2026-09-21. AGENTS.md의 엔진 변경 전 기대값 작성 규칙을 적용했다.

## 먼저 정의한 기대

- 초기 기본 요약에서 전력·용수·통신 미확인을 항상 표시한다. 면적·비용·차입잔액의 선택 미입력은 전체 확인사항에는 남지만 기본 요약 오류로 표시하지 않는다.
- 조례 검토는 현재 용도지역 출처(`manual`/`auto`/생략)를 보존한다. 이 항목만으로 확인된 법적 제한이나 중대 제약 문구를 만들지 않는다.
- 번들 법적 제한은 실시간 조회 실패에도 확인사항·E 상한으로 유지한다. 실패한 자료는 별개의 미확인이다.
- 재해 해당은 조회된 검토 대상이며 인허가 결론이나 별도 E 상한이 아니다.
- 공급 협의의 사용자 확인은 유효한 내용·날짜가 있어야 하며 기관 확약 검증이 아니다.
- 다음 행동은 기존 이슈에서 제약 → 미확인 → 입력조건 순으로 생성하고 같은 분류 안에서는 기존 분기 순서를 유지한다.
- 최소 대지 15,000㎡, 부족 5,000㎡, 60억원 금융비용, 비용 null/0, 기존 대표 점수·18항목·후보 재계산을 유지한다.
