# 09 운영 보고서 출처 문구 보정

2026-09-21 KST. 운영 배포 `da8f9f7235c6d01aa008c406e2bc44d6c254b40a`의 실제 좌표 조회와 새 11쪽 A4 PDF에서, 조회가 완료된 담은 후보에도 `자동 조회·미확인`이 표시되는 것을 실행자와 root가 각각 관찰했다. `manualLandUse === null`인 모든 후보에 출처와 상태가 혼합된 고정 문자열을 적용한 결과다.

`ChecklistReport.tsx`의 이 문자열 한 곳만 **자동 조회 기준**으로 바꾼다. 사용자 선택 표시는 그대로이며, 조회 완료·부분·실패·시각은 기존 `OnlineStatus`가 표시한다. 산식·응답 계약·상태 로직·인쇄 CSS는 바뀌지 않는다.

타입·린트·전체 Vitest 47파일 563건·빌드·diff 검사 5종은 종료0이다. 빌드 JS 해시가 바뀌므로 후속 PR/Ready 확인 후 공개 정적 파일 해시, 변경 문구 DOM, 비로그인 업무 흐름, 새 운영 PDF 전 페이지를 검수한다. 기존 08의 5PDF·53쪽은 이전 빌드 근거로 계승하며 자동으로 최신 PDF 검수라고 주장하지 않는다.

수정 전 운영 PDF는 SHA-256 `14b39f99cd38ad44a6ffc844596225c3c57cb213451d6a9728476c545a503c36`, 11쪽이었다. 원본·입력기록·추출·전체 렌더·검수는 작업 증거 `09-operating-output-before-label/`, `09-operating-pdf-before-label/`에 보존했다. 이는 최종 배포 후 생성할 PDF와 구분한다.

같은 운영 배포에서 VWorld 5개 JSON과 제품 요청형식 WMS1.3.0 PNG가 정상 반환됐다. 초기 점검용 WMS1.1.1 요청의 실패도 보존했다. AI는 HTTP200이어도 오류 마커를 반환했고, 실제 UI 한 번 재시도도 실패 안내로 종료됐다. 실패 후 기본 보고서 열기와 AI 부록 제외가 정상 동작했다. 무료 모델 목록·권한·제한은 바꾸지 않았고 AI 생성 성공으로 기록하지 않는다.

최종 배포·운영 검수 결과는 [09 운영 인계](09-reproduction-deployment.md)에 연결한다.
