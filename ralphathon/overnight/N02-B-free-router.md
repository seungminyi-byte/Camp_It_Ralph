# N02-B — 기본 무료 경로의 마지막 대안 추가

작성 2026-09-22T00:44:51.636950+09:00. N04의 텍스트 출력 전504/timeout 관측을 근거로 `openrouter/free`를 기본3모델 뒤 네번째에만 추가했다. 이 식별자는 기존 allowlist에 이미 있었으며 환경값·요금정책·기존우선순위는 유지한다. 다른 명시모델은 단일경로다. 서버 fetch는 여전히1회이며 별도 재시도나 시간·크기·파서 완화는 없다.

구현 전에 기대값을 고정했다(SHA `801b5cbca5276361b99568dbc7a8217d01e65e21d1c2f56e0ccbec045dd18b58`). 변경된 기대값의 초기124검사는118통과/6실패였고 실패는 모두 기본목록이3개였기 때문이다. 제품1행을 바꾼 후 API 9파일 290검사가 통과했다. 독립대조40사례에서 요청목록의 허용된 차이를 제외한 응답상태·본문·헤더·상위호출수가 이전 결과와 같았다. API타입과 소유파일lint도 통과했다. 실제 네트워크 호출은0이다.

README에 한 요청의 fallback 목록이며 각모델의 실제 시도·성공을 보장하지 않는 점을 명시했다. 실제 모델 선택은 OpenRouter에 달려 있다. 독립 실행자 검수·기존 배포·실제 합성 요청 관측은 아직 남았으며 복구완료로 표시하지 않는다.
