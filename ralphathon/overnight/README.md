이 실행 기록 안의 `../../../overnight/...` 링크는 원래 작업 디렉터리의 중간 근거를 가리킵니다. Git 저장소만 복제하면 해당 로컬 근거는 포함되지 않습니다. 원본 보고서와 파일 해시를 보존하기 위해 이 링크를 과거 근거와 다른 내용으로 바꾸지 않았습니다. 사용자 전달본은 필요한 근거를 선별해 상대 링크가 내부에서 열리도록 별도로 제작합니다. 원시 세션·키·계정 설정은 Git이나 일반 전달 ZIP에 넣지 않습니다.

원래 발표·운영 PDF·9월 21일 전달 ZIP은 유지합니다. 야간 후속의 최종 상태, 로그 cutoff, 예약 종료, 본인 프로세스 정리와 최종 묶음은 09:00 이후 실제 근거로 확정합니다. 10:00 하드 마감과 별도 승인 대상은 그대로 적용합니다.
