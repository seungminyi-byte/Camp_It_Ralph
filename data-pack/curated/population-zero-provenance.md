# SGIS 명시적 0 격자 복구

2026-09-22 [공식 SGIS 격자 통계 및 경계](https://www.data.go.kr/data/15141768/fileData.do)를 다시 수집했다. 2024년 통계, 2025-06-30 경계, 무료·이용허락범위 제한 없음으로 안내된다.

- 원본 ZIP: 98,426,954바이트, SHA-256 `5cc8631e4863dfa3c9aabef043ddc53ff6e2ac22df94ae5dccb2928b669b02a6`.
- `to_in_001` 총인구: 75,070행 = 양수 73,016 + 명시적 0 2,054. 각 격자 식별자는 유일하다.
- 이전 전처리는 `p <= 0`을 모두 버렸다. 이제 원문에 명시된 정수 0을 보존하며, 미수록·빈칸·N/A·음수·유효하지 않은 값은 0으로 바꾸지 않는다. 총인구가 없는 경우 나이대별 값을 합쳐 대체하지 않는다.
- 기존 양수 73,016행의 좌표·값·순서가 모두 동일하고 전체 합계 51,826,577도 동일하다. 새 0 격자는 원문 SHP의 같은 좌표 변환 관례로 추가한다.

ZIP의 통계자료 이용안내는 작은 값을 0 또는 5로 확률 대체하는 비밀보호 처리를 설명한다. 포털과 ZIP에서 기법 명칭이 달라 UI에는 특정 알고리즘명을 단정하지 않고 **비밀보호 조정**으로 설명한다. 공개 통계값 0은 실제 무거주나 민원 없음의 증거가 아니다. 인구가 0으로 표시되는 화면·비교·보고서는 이 한계를 인접 표시한다.

이 변경은 자료 누락을 실제 0으로 채우는 것이 아니라 이미 공표된 값을 보존하는 것이다. 인구 감점 기준·가중치·법적 제한은 변경하지 않는다. 알려진 통계 행이 하나도 없는 범위의 점수는 계속 보류한다.

좌표 관례는 기존 p03과 동일한 SHP 꼭짓점 평균이다. 닫힘 중복점 때문에 기하학적 중심과 다를 수 있으며, 이번 검수는 기존 좌표의 보존과 원문 재현을 확인한 것이지 정확한 필지/행정경계를 새로 확보한 것이 아니다.
