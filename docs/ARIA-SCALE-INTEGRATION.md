# ARIA 규모·사업 유형 통합

2026-09-08 기본 브랜치 `4ef4cab`에 ARIA `59a5fb7`, `62f3ef8`을 이력 보존 병합한다. 기존 작업 폴더의 README 수정과 미추적 AGENTS.md는 포함하지 않는다.

## 변경과 충돌 해결

- 규모 `type`(엣지·일반·초대형)와 사업 유형 `businessType`(일반 클라우드·코로케이션·AI 데이터센터)을 분리한다. 기본값은 일반 규모·일반 클라우드다. 목표 수전용량·IT부하·면적·비용·점수 산식은 선택만으로 바뀌지 않는다.
- 상수 원본의 규모 설명과 화면·비교·보고서·AI 문맥을 일치시킨다. 상수는 `build_all.py --sync-only`로 검증·동기화했다.
- 결과 요약과 테스트 2곳의 충돌은 기존 엔진의 `area.hasInputs/fitPct`, `review.overview`를 보존하며 해결했다. 접힌 초기 요약과 별개로 전체 미확인 근거는 보고서·AI에 남는다.
- 분야별 가중점수는 엔진에서 계산한다. 45%·55% 가중치에 필요한 소수 둘째 자리까지 표시하고 합계 반올림과 법적 제한 E등급 상한을 설명한다. 아리아 원안의 소수 첫째 자리 반올림으로 표시 합계가 달라질 수 있는 문제를 보완했다.
- 미산정과 조회 중을 구분한다. 법적 제한 붉은 배지, 재해 15점 1회, 해상·자료 범위 밖·조회 실패 보류를 유지한다.

## 검증

- 타입 검사(앱/API/scripts), 린트, Vitest 18개 파일 162개 테스트, 데이터 검증, 프로덕션 빌드 통과.
- 규모와 사업 유형의 9개 조합에서 면적·금융비용·조건·점수 보존, 비교 입력 전달, AI 평가 서명 변경을 검증했다. 보고서·비교의 새 표기도 확인했다.
- Browser 실제 입력: 10,000㎡ ↔ 3,025평, 연면적 30,000㎡·용적률 200%·건폐율 50%·4층 → 최소 대지 15,000㎡·부족 5,000㎡·충족률 67%. 평균 차입잔액 1,000억원·6%·12개월 → 60억원.
- 데스크톱 1440px·태블릿 768px·모바일 375px에서 가로 넘침, 규모 선택·입력 접기/펼치기를 확인했다. 후보 담기와 AI 없는 기본 보고서 출력도 확인했다.
- 실제 보고서 DOM과 빌드 인쇄 CSS를 WeasyPrint로 A4 5쪽 렌더링해 전 페이지를 확인했다. 표 폭과 면적 단위의 우측 여백을 보완했으며 첫 장 요약·민감도 표·18개 근거·전체 추가 확인사항이 유지된다. 브라우저/프린터별 페이지 구분은 달라질 수 있다.
- 실조회 좌표 36.4916, 127.3046은 보전녹지지역·도시자연공원구역 조회로 E49였다. 고정 테스트의 별도 좌표·조회 조건 결과와 혼동하지 않는다.
