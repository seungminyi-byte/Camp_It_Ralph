# 후보 부지 1차 사업검토 — 데모와 검증

2026-09-08 개편 기준입니다. 목표는 제안받은 부지에서 검토를 막는 근거와 면적·비용·공급조건의 누락을 찾아 후속 확인사항을 정리하는 것입니다. 높은 참고점수를 받는 부지를 추천하는 시연이 아닙니다.

## 5분 시연

1. 주소나 좌표로 후보를 선택합니다. 읍면동 중심점은 실제 필지가 아니라는 점을 안내합니다. 공개자료 조회가 끝날 때까지 기다리고, 실패한 항목은 미확인으로 설명합니다.
2. 일반 클라우드, 목표 수전용량 40MW, 신축을 선택합니다. 대지 10,000㎡, 계획 연면적 30,000㎡, 적용 용적률 200%, 건폐율 50%, 지상 4층을 입력합니다. **이론상 최소 대지 15,000㎡, 부족 5,000㎡**를 확인합니다. 이 수치는 계산 검증용 가정입니다.
3. 대지를 15,000㎡로 바꿔 ‘단순 면적조건 충족’을 확인합니다. 실제 배치·옥외설비·주차·높이·이격거리 검토는 남아 있음을 설명합니다. 10,000㎡는 3,025평이고 단위 왕복 시 원래 면적이 유지됩니다.
4. 유형을 AIDC로 바꿉니다. 목표 수전용량과 부지별 비용이 덮어써지지 않고 공급 가능 MW가 생기지 않는 것을 확인합니다. 상세 설계방식은 IT부하·랙 전력·랙 면적·전산실 비중이 모두 있어야 계산됩니다.
5. 주변 인구·가구 수와 학교까지 직선거리를 봅니다. 뉴스 0건도 수용성이 좋다는 뜻은 아닙니다. 가구 결측과 부분 합계, 학교 지점거리의 한계를 표시합니다.
6. 비용에서 토지비 500억원, 건축·설비비 1,500억원만 입력합니다. ‘입력된 비용 합계 2,000억원’과 나머지 항목 미입력을 확인합니다. 평균 차입잔액 1,000억원, 금리 중 하나 6%, 기간 12개월을 입력하면 해당 금융비용은 **60억원**입니다. 금리·기간은 전망이 아닌 계산 가정입니다.
7. 후보를 담고 다른 주소를 선택합니다. 부지별 면적·비용은 새로 입력하고 공통 사업·설계·금리 조건은 유지합니다. 후보를 다시 열면 이전 부지 조건이 복원됩니다. 비용 누락이 있는 후보 사이에는 최저비용·차액을 제시하지 않습니다.
8. ‘부지 검토 보고서’를 엽니다. AI를 실행하지 않아도 사업조건·제약·면적·비용표·확인사항을 볼 수 있고 PDF로 출력할 수 있습니다. 상세 자료 출처와 협의 내용은 다음 장에 있습니다. AI 의견 생성 후 조건을 바꾸면 기존 의견이 해제됩니다.

## 반례 시연

| 상황 | 확인할 동작 |
|---|---|
| 필수 면적·IT 설계계수 누락, 0·음수 | 면적 계산 보류, 필요한 입력 명시 |
| 기존 건물 전환 | 확보 건물 연면적과 비교, 구조하중·층고·장비 반입·냉각설비 확인사항 |
| 차입잔액 미입력 | 금융비용 계산 보류. 총사업비를 차입잔액으로 대입하지 않음 |
| 전력 목록 미등재·필수 조회 실패 | 종합점수 미산정, 미등재만으로 D 상한·부적합 처리하지 않음 |
| 보호·규제구역 해당 | E등급 상한과 붉은 배지, 근거·기본 보고서 유지 |
| 재해위험지구 해당 | 기존 15점 감점·추가 확인. 재해만으로 E 상한 적용 안 함 |
| 뉴스 미수집 / 기사 0건 | 미확인과 수집 범위 내 0건 구분, 뉴스·사례 감점 없음 |
| 해상 좌표 37.4, 126.2 | 해상·수역 설명, 비교·보고서 대상에서 제외 |
| 북한·국외·먼바다 | ‘자료 범위 밖’, 판독 불가. 낮은 위험으로 해석하지 않음 |

## 검증 방법

```bash
npm --prefix prototype run typecheck
npm --prefix prototype run lint
(cd prototype && node node_modules/vitest/vitest.mjs run)
python3 data-pack/scripts/validate_out.py
npm --prefix prototype run build
```

가구 원본 재생성은 `p09_households.py` 실행 후 검증·동기화합니다. 현재 번들은 107,680개 격자, 값 확인 74,723개, 결측 32,957개입니다. 원본 SHA-256과 가공 버전으로 출처를 추적합니다.

2026-09-08 로컬 검증 결과: 타입 검사, 린트(경고 없음), 16개 파일의 129개 테스트, 데이터 검증, 프로덕션 빌드 통과. 브라우저에서 15,000㎡ 최소 대지·5,000㎡ 부족, 3,025평 왕복, 6%·12개월 60억원, 부지별 비용 복원과 차액 보류를 확인했습니다. 입력을 바꾼 뒤 원래 값으로 되돌려도 중단된 AI 의견은 다시 활성화되지 않고 기본 보고서는 계속 출력됩니다.

실제 보고서 DOM의 A4 렌더링은 검증 예시에서 5장입니다. 첫 장에 조건·제약·면적·민감도 표·확인사항·주의 문구가 들어가고 상세 18개 항목과 출처가 이어집니다. 빈 페이지·표/글자 잘림 없이 확인했으며, 실제 프린터 드라이버와 브라우저별 페이지 구분은 달라질 수 있습니다. 이 단락은 로컬 인쇄 검증 기록이며 운영 검증은 아래에 구분합니다.

화면 검증은 데스크톱 1440px, 모바일 375px, 태블릿 768px에서 입력·단위 전환·후보 복원·가로 넘침을 확인합니다. A4는 실제 보고서 DOM과 인쇄 CSS를 렌더링해 첫 장 요약, 표 머리글, 글자 잘림과 빈 페이지를 확인합니다. 브라우저별 인쇄 설정에서는 A4와 기본 배율을 사용하세요.

## 오프라인·후속 항목

번들 자료와 기본 보고서는 외부 AI 없이 사용할 수 있습니다. 주소 검색, 지도 타일, VWorld 조회는 온라인 기능이므로 오프라인에서는 좌표·읍면동 검색과 사용자 용도지역 보완을 사용하고 조회 미확인을 유지합니다. v4 평가 서명이 같은 사전 생성 의견만 허용하며 일치하는 의견이 없어도 기본 보고서는 출력합니다.

기후 원본 파일셋은 응답 지연으로 확보하지 못했고 IC 서비스 인증·응답은 미검증입니다. 현재 화면에 두 자료가 없음을 명확히 안내합니다. [수집 완료 조건](PLAN.md#5-후속-수집의-완료-조건)과 [자료 한계](DATA.md)를 확인하세요.
