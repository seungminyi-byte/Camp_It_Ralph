- 재해위험지구 점 조회를 화면·14행 체크리스트·AI 의견·비교에 연결. 인허가 15점 단일 감점, 별도 상한 없음.

- 연안 혼합 셀에서 정상 조회 결과 도형이 없어도 육지 미확인으로 보류. 수동 육지 간주 제거.

- 비교 재계산에 규제·재해 근거 보존. 생성 의견은 조건 변경 시 갱신 필요 표시. 사전 생성 메모는 v3 평가조건 서명 확인.
- API 테스트를 함수 배포 경로 밖으로 이동. 기존 보호구역 E 상한·붉은 배지·자료 범위 표현 유지.
