## SGIS 가구 가공과 검증

원본 `data-pack/raw/sgis_grid/sgis_grid.zip`은 인구 수집 때 확보한 동일 ZIP입니다. 새 키가 필요 없습니다. `p09_households.py`는 다음을 수행합니다.

1. 가구 CSV의 총가구수 `to_ga_001`만 선택하고 기준연도 2024와 격자코드 형식을 검사합니다.
2. 중복 코드의 값이 다르면 실패합니다. 읽을 수 없는 비수치 값은 결측으로 보존합니다.
3. 경계 SHP의 격자 식별자를 확인하고 EPSG:5179 격자의 중심을 WGS84로 변환합니다. 모든 값 코드가 경계에 연결되는지 확인합니다.
4. 전국 경계 셀을 출력합니다. 값이 없는 셀은 null이며 중복 좌표·범위·부산/제주/강릉 자료 존재를 검증합니다.
5. `households_grid.json`에 출처 URL·2024·지표코드·가공 버전 p09-v1·원본 SHA-256을 저장합니다. `build_all.py`가 검증 후 앱에 복사합니다.

가공된 유효값 합계는 22,321,130가구입니다. **비밀보호 값 조정이 있는 격자 합계**이며 주민등록 세대 총계나 정확한 필지 주변 가구 수로 인용하지 않습니다. 일부 격자만 확인되면 부분 통계로 표시하며, 모두 미확인이거나 파일을 읽지 못하면 가구 수를 미확인으로 남깁니다. 추가 가구 감점은 없습니다.

인구 자료는 기존 전국 처리 결과를 유지합니다. 2026-09-05 이전의 수도권·대조군 21,944셀 한정본은 현재 사용하지 않습니다.

## 공간·규제 처리

- 자료 범위는 bbox 33~38.7°/124.5~132°, 휴전선·NLL 근사선과 최근접 읍면동 중심점 거리로 정합니다. 범위 밖은 ‘판독 불가 · 자료 범위 밖’이며 점수·비교·보고서를 제공하지 않습니다.
- 해상·수역은 점수를 주지 않습니다. 연안 혼합 셀에서 육지 근거가 불충분하거나 조회 실패 시 판정을 보류합니다.
- 2000년 이후 매립한 송도·새만금·시화 등은 SRTM 수역 오인식이 있어 `reclaimedOverrides`와 VWorld 용도지역 근거로 보완합니다. 내륙 수면과 연약지반은 별도 확인해야 합니다.
- 법적 입지 제한: 감점 40과 E등급 상한·붉은 배지. 규제 검토: 감점 15. 필요한 자료가 미확인이어도 확인된 제한은 해제하지 않습니다.
- 번들 보호지역과 VWorld의 `LT_C_UD801`, `LT_C_UM710`, `LT_C_UO301`, `LT_C_AGRIXUE101`, `LT_C_UQ162`는 별도로 추적합니다. 국가유산 500m 조회는 검토 범위이며 정식 보호구역 자체와 구분합니다.
- 군사시설보호구역은 미반영입니다. 공개 도형이 없다고 제한이 없다는 의미가 아닙니다. 토지이용계획확인서와 고시 도면이 우선합니다.
- 재해위험지구 레이어를 규제구역으로 다시 집계하지 않습니다. 서로 다른 법정 규제와 재해 위험은 각각 검토하며 재해만으로 E등급 상한을 만들지 않습니다.

## 기존 데이터 수집 운영

건축HUB는 법정동 코드별 페이징 후 허가일·연면적을 로컬에서 필터합니다. 통계 표본 부족은 미확인으로 표시하며 현재 부지의 지연 예측으로 사용하지 않습니다.

뉴스는 NAVER API HUB의 `naverapihub.apigw.ntruss.com/search/v1/news`와 `X-NCP-APIGW-*` 헤더를 사용합니다. 신규 키에 기존 개발자센터 방식은 적용하지 않습니다. 지역·데이터센터·갈등 키워드는 제목으로 확인하고 링크·제목 중복을 제거합니다. 기사 합계는 검색 범위 내 건수로만 해석합니다. 과거 뉴스 감점 밴드와 주민 갈등 등급은 폐기했습니다.

전력 지역 참고값에 사용한 과거 시장 통계는 `constants.stats`의 출처와 기간을 따릅니다. 기술검토 736건 기간은 2024-08-01~2026-03-27이며 현재 시점의 전체 시장 확률이 아닙니다. 한전 공급 여유용량은 발전접속 기준으로 수전 판단에 직접 쓰지 않습니다.

## 후속 수집: 검증 전 화면에 미반영

- [기상청 평년값](https://data.kma.go.kr/climate/average30Years/selectAverage30YearsKoreaList.do): 공식 페이지에서 1991~2020 자료와 기간별 파일셋 제공을 확인했습니다. 2026-09-08 파일셋 경로(`selectAverage30YearsKoreaFileset.do?pgmNo=716`)는 직접 요청과 웹 조회에서 timeout이 발생해 원본 확보·이용조건·가공 검증을 완료하지 못했습니다. 월 평균/평균 최고기온/습도·관측소 위치·관측기간을 확보한 뒤 정적 번들로 추가합니다. 가까운 관측소 값과 거리를 표시하되 부지 실측이나 냉각 비용으로 환산하지 않습니다.
- [한국도로공사 출입시설](https://www.data.go.kr/data/15076687/openapi.do): 좌표 제공, 무료, 이용허락범위 제한 없음, 연결 서비스 방식임을 확인했습니다. 사용자는 포털에서 연결된 서비스의 활용신청·인증키를 확인해야 합니다. 현재 연결 서비스 인증과 실제 응답은 미검증이며 UI에는 반영하지 않았습니다. 공식 구분값으로 IC만 추출하고 분기점·휴게소를 제외한 뒤 좌표·중복을 검증합니다.
- [K-water 용수 공급 안내](https://m.kwater.or.kr/water/sub08/waterInfoPage.do?s_mid=2022): 사전 문의와 검토 절차를 참고합니다. 시설용량을 특정 부지의 공급 가능량으로 해석하지 않습니다. 현재는 용수 협의 상태·내용·날짜와 공급기관 확인사항을 제공합니다.

전국 필지·건축물대장·토지 매입가 자동 추정·통신 및 송전선로 상세 경로·철도역은 이번 수집 범위에서 제외했습니다.


## 인근 데이터센터 지도 목록

2026-09-08 ARIA 후보 7곳 중 출처·주소·이용조건을 검토한 2곳을 수록했다. 전국 전수 목록과 실시간 운영 확인이 아니며 시설 미표시는 주변 시설 없음이 아니다. 수록 사실·제외 이유·좌표 응답은 [통합 검증 기록](ARIA-NEARBY-INTEGRATION.md#지도-자료-검증)을 따른다. 원본은 `data-pack/curated/data_centers.json`, 동기화는 `build_all.py --sync-only`다. 목록 오류는 자료 미확인으로 격리하며 점수에 영향을 주지 않는다.
