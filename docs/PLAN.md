2026-09-08 회의 의견과 승인된 개선 계획을 반영했습니다. 주 사용자는 개발·사업검토 담당자이며, 여러 경로로 제안된 후보를 빠르게 검토하고 내부 보고와 후속 확인에 활용합니다.

## 2. 입력과 산식

공통 `ProjectAssumptions`는 규모(type), 사업 유형(businessType), 목표 수전 MW, 개발 방식, 면적 산정 방식, IT MW, 랙 kW, 통로 포함 랙당 ㎡, 전산실 비중, 금리 3개와 기간 3개를 보관합니다. 기존 식별자 standard/small/hyperscale는 각각 일반/엣지/초대형으로 표시하며 용량을 내포하지 않습니다.

부지별 `SiteConditions`는 대지·계획 연면적·확보 건물 면적, 용적률·건폐율·지상층수, 비용 방식과 항목, 평균 차입잔액, 세 종류 협의 기록을 보관합니다. 미입력은 null입니다.

- 기본 방식: 계획 연면적 직접 입력.
- 상세 방식: `랙 수 = ceil(IT부하 MW × 1,000 ÷ 랙당 전력 kW)`.
- `필요 연면적 = 랙 수 × 통로 포함 랙당 면적 ÷ (전산실 비중 % / 100)`.
- 신축: `최소 대지 = max(필요 연면적 / (용적률 % / 100), 필요 연면적 / 지상층수 / (건폐율 % / 100))`.
- 기존 건물 전환: `면적 부족 = max(0, 필요 연면적 − 확보된 건물 연면적)`.
- `지연 금융비용 = 지연 중 평균 차입잔액 × 연 금리 × 지연개월 / 12`.

신축은 전 면적 지상·용적률 산입·층별 동일 면적을 가정합니다. 필요한 양수 누락, 0·음수·비유한값, 건폐율/전산실 비중 100% 초과, 소수 층수는 계산 보류입니다. 비용·차입잔액은 명시적 0을 허용합니다. 부동소수점 범위 초과도 보류합니다.

초기값은 일반 규모·일반 클라우드·신축·직접 면적 방식과 금리 4.5/5.5/6.5%, 기간 6/12/24개월뿐입니다. 금리·기간은 수정 가능한 계산 가정입니다. 실제 면적·설계계수·인입비·차입잔액에는 임의 기본값을 넣지 않습니다.

회의에서 언급한 엣지 2,500평·20MW 5,000평·40MW 10,000평·80MW 20,000평은 경험적 연면적 예시입니다. 전력 기준·시설 유형·적용 조건이 확인되지 않아 자동 계산값으로 사용하지 않습니다.

## 3. 참고점수와 해석

전력·인허가의 기존 기본 가중치는 유지합니다. 유형별 임의 감점배수, 변전소 개수에 따른 MW 추정·유형별 합격조건, 미등재 D등급 상한, 뉴스·사례 감점, 주민 갈등 등급, 점수 기반 지연기간은 제거했습니다.

전력은 읍면동 자료·최근접 위치가 확인된 때 계산합니다. 인허가는 행정구역·용도지역·인구·학교·지형과 규제/재해 조회가 확인되어야 계산합니다. 필요한 자료가 없으면 종합점수와 등급은 미산정입니다. **법적 입지 제한이 확인되면 점수 산정 여부와 별개로 E등급 상한과 붉은 배지**를 표시합니다. 제한 감점 40점, 규제 검토 15점, 재해위험지구 15점 1회 적용과 별도 E 상한 없음은 유지합니다.

가구는 주변 현황에만 추가하며 기존 인구 감점과 중복하지 않습니다. 뉴스 0건과 미수집 지역을 구분합니다. 수용성 등급과 뉴스 감점은 없습니다. 수집된 지역 조례나 사례가 없다고 규제·갈등이 없다고 판단하지 않습니다.
