## 아키텍처 (핵심 결정)

- **런타임 외부 API 의존 제로** 기본: 데이터 전부 빌드 번들(~2MB). 온라인 필요한 건 지도 타일과 GenAI 호출뿐 → 데모 불사(不死)

- 육지/수역·경사: 폴리곤 대신 **SRTM 기반 0.01° 격자**(`terrain_grid.json`, base64 uint8 4 plane) 빌드타임 번들

- 스택: React+TS(strict)+Vite, Leaflet+OSM, Tailwind, vitest. 차트·라우터·상태관리 라이브러리 없음
- 스코어링 엔진은 UI 분리 순수 TS 모듈 + 골든 테스트. 가중치는 `constants.json` 외부화
- GenAI: 런타임 "실사 체크리스트 검토 의견"(스트리밍) — 키는 서버에만(Vercel 프록시 → 프리컴퓨트 폴백) +
  빌드타임 뉴스 갈등단계 분류(P1)

### 스코어링 요지

- 전력 축(0~100): 게이트(읍면동 공급가능 변전소 0곳 → 상한 40 + 적색 배지) +
  0.45·변전소수 + 0.30·시도 프라이어(서울 20/경기·인천 45/비수도권 90) + 0.25·OSM 변전소 거리.
  확보 전력은 숫자 아닌 **밴드**("40MW+ 검토 가능" 등). 발전접속≠수전 disclaimer 상시
- 인허가 축(100−Σ감점): 반경 500m 인구·학교 거리·용도지역·지자체 규제 이력·갈등 사례 근접·뉴스 시그널(P1)·처리 지연 통계(P1)
- 종합 = 0.45·전력 + 0.55·인허가 → A~E 등급 → 지연 밴드(사례 앵커: C=고양 덕이 9개월, E=김포 구래 30개월+) →
  금융비용 = 총사업비(기본 5,000억, 40MW급) × 금리(5.5%) × 지연/12. 슬라이더로 가정 조정
- 카드에 **감점 사유별 근거·출처·앵커 사례** 노출 — 설명 가능성이 심사 설득 장치
